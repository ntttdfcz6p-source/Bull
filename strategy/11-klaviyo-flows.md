# Suggested Klaviyo Flows

| Flow | Trigger | Key jobs | Notes |
|---|---|---|---|
| Welcome / Subscription Onboarding | Signup or first order | Restate Start Kit terms in full (price, recurring price, frequency, cancel/skip), set expectations for delivery timing | Must match purchase-module disclosure exactly — no drift between site copy and email copy |
| Browse Abandonment | Viewed product offer page, no Add to Cart | Reinforce positioning line + one proof element, single CTA back to offer page | Cap at 1–2 emails, low frequency — this is a premium brand, not a high-pressure funnel |
| Cart Abandonment | Added to cart, no checkout | Show selected tier's real price/savings math, subscription terms reminder, guarantee reminder | 2–3 email sequence, escalating proof, never inventing urgency (no fake "only 3 left") |
| Checkout Abandonment | Started checkout, didn't complete | Remove friction (shipping cost transparency, guarantee), single CTA to resume checkout | 1–2 emails |
| Order/Shipping Confirmation | Order placed / shipped | Set delivery expectations, restate subscription terms if applicable | Transactional, always sent |
| Review Request | 14 days post-delivery | Request verified review (see `08-review-ugc-plan.md`), incentive not conditioned on sentiment | Route negative sentiment to support in parallel |
| Replenishment Reminder (one-time buyers) | ~[PLACEHOLDER: days before bottle runs out, pending confirmed serving size] | Encourage repeat one-time purchase or subscription conversion | Timing depends on final serving size — do not hardcode until confirmed |
| Subscription Pre-Shipment Notice | X days before next charge | Transparent reminder of upcoming charge + amount + skip/pause link | Required for trust — never let a renewal be a surprise |
| Skip/Pause Save Flow | Customer initiates skip or cancel | Ask reason (feeds `09-ltv-framework.md` churn data), offer a real, disclosed retention option (e.g., delay vs. discount) — never a dark-pattern "are you sure?!" loop | One retention offer max, then respect the choice |
| Win-Back | Canceled or lapsed X days | Re-engagement offer, framed around returning to the routine, not manufactured scarcity | |
| Post-Purchase Cross-Sell (future SKUs) | 60–90 days into an active subscription | Introduce a future complementary product once one exists | Placeholder flow — do not build fake product content into it prematurely |
| VIP / High-LTV Recognition | Customer crosses a cohort-defined LTV threshold (see `09-ltv-framework.md`) | Early access to future products, loyalty recognition | Threshold TBD once real LTV data exists |
