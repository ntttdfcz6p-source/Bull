# BullFuel

BullFuel — "Fuel Your Edge" — premium men's daily-vitality gummy brand. This repo contains the full launch strategy package and the Shopify theme build for the flagship product, **BullFuel Male Vitality Gummies**.

- **`/strategy`** — brand application guide, funnel wireframes, pricing framework, welcome offer, proof/UGC plans, LTV framework, upsell/Klaviyo/A/B-test plans, mockup prompts, and the facts-vs-placeholders-vs-legal-review register. Start at `/strategy/README.md`.
- **`/shopify-theme`** — the Online Store 2.0 theme implementing the brand homepage, the direct-response landing page, and the focused product offer page, all sharing one purchase-module component. Start at `/shopify-theme/README.md`.

**Read `/strategy/README.md`'s "Known gap" note and `/strategy/14-facts-placeholders-legal.md` before treating anything in this repo as launch-ready** — this build was produced without the actual logo file, source transcripts, or product formula sheet ever being attached to the session, so it's built from the brief's own description of them, with every unverified figure explicitly marked `[PLACEHOLDER]`.
